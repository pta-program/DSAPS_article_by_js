## 题目描述

给定一系列由大写英文字母组成的字符串关键字和素数 P，使用以下两步散列方法将关键字映射到散列表中：

1. **移位法**：将关键字 Key 的最后 3 个字符映射为整数，每个字符占 5 位（即基数为 32）
2. **除留余数法**：将上述整数对 P 取余，得到散列表位置

字符串长度不足 3 位时，按实际长度处理。发生冲突时使用**平方探测法**解决。

### 示例说明

以字符串 AZDEG 插入长度为 1009 的散列表为例：
- 将大写字母 A~Z 顺序映射到整数 0~25
- 取最后 3 个字符 DEG：D=3, E=4, G=6
- 通过移位计算：3×32² + 4×32 + 6 = 3206
- 除留余数：3206 % 1009 = 179，即散列映射位置为 179

## 输入格式

1. 第一行给出两个正整数 N（≤500）和 P（≥2N 的最小素数），分别为待插入的关键字总数和散列表长度
2. 第二行给出 N 个字符串关键字，每个长度不超过 8 位，以空格分隔

## 输出格式

在一行内输出每个字符串关键字在散列表中的位置，数字间以空格分隔，行末尾不得有多余空格。

## 输入样例 1

```in
4 11
HELLO ANNK ZOE LOLI
```

## 输出样例 1

```out
3 10 4 0
```

## 输入样例 2

```in
6 11
LLO ANNA NNK ZOJ INNK AAA
```

## 输出样例 2

```out
3 0 10 9 6 1
```

## 样例说明

以样例 1 中的 HELLO 为例：
- HELLO 长度为 5，取最后 3 个字符 LLO
- L=11, L=11, O=14
- 移位计算：11×32² + 11×32 + 14 = 11630
- 除留余数：11630 % 11 = 3，即位置为 3
