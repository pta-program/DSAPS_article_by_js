## 7-13 统计工龄

- **分值：** 20分

## 题目描述

给定公司 n 名员工的工龄，要求按工龄增序输出每个工龄段有多少员工。

## 输入格式

输入首先给出正整数 n（\le 10^5），即员工总人数；随后给出 n 个整数，即每个员工的工龄，范围在 [0, 50]。

## 输出格式

按工龄的递增顺序输出每个工龄的员工个数，格式为：“工龄:人数”。每项占一行。如果人数为 0 则不输出该项。

## 输入样例
```
8
10 2 0 5 7 2 5 2
```

## 输出样例
```
0:1
2:3
5:2
7:1
10:1

```

## 解题思路

本题采用计数数组，围绕题目给出的数据结构和约束完成核心计算，并处理边界情况。

## 代码流程说明

1. 读取题目规定的输入数据。
2. 使用计数数组完成主要处理。
3. 处理边界情况并整理结果。
4. 按指定格式输出结果。

## 代码实现


```javascript
const fs = require("fs");
const raw = fs.readFileSync(0, "utf8");
const tokens = raw.trim() ? raw.trim().split(/\s+/) : [];
let at = 0;

// 工龄范围固定为 0~50，直接计数后按下标输出。
const n = Number(tokens[at++]),
  count = Array(51).fill(0);
for (let i = 0; i < n; i++) count[Number(tokens[at++])]++;
const out = [];
for (let age = 0; age <= 50; age++)
  if (count[age]) out.push(`${age}:${count[age]}`);
console.log(out.join("\n"));
```
