## 7-21 求前缀表达式的值

- **分值：** 25分

## 题目描述

算术表达式有前缀表示法、中缀表示法和后缀表示法等形式。前缀表达式指二元运算符位于两个运算数之前，例如`2+3*(7-4)+8/4`的前缀表达式是：`+ + 2 * 3 - 7 4 / 8 4`。请设计程序计算前缀表达式的结果值。

## 输入格式

输入在一行内给出不超过30个字符的前缀表达式，只包含`+`、`-`、`*`、`/`以及运算数，不同对象（运算数、运算符号）之间以空格分隔。

## 输出格式

输出前缀表达式的运算结果，保留小数点后1位，或错误信息`ERROR`。

## 输入样例
```
+ + 2 * 3 - 7 4 / 8 4
```

## 输出样例
```
13.0
```

## 解题思路

本题采用栈求前缀表达式，围绕题目给出的数据结构和约束完成核心计算，并处理边界情况。

## 代码流程说明

1. 读取题目规定的输入数据。
2. 使用栈求前缀表达式完成主要处理。
3. 处理边界情况并整理结果。
4. 按指定格式输出结果。

## 代码实现


```javascript
const fs = require("fs");
const raw = fs.readFileSync(0, "utf8");
const tokens = raw.trim() ? raw.trim().split(/\s+/) : [];
let at = 0;

// 从右向左扫描前缀表达式：数入栈，遇到运算符弹出左、右操作数计算。
const items = raw.trim().split(/\s+/),
  stack = [],
  ops = new Set(["+", "-", "*", "/"]);
for (let i = items.length - 1; i >= 0; i--) {
  const item = items[i];
  if (!ops.has(item)) stack.push(Number(item));
  else {
    const left = stack.pop(),
      right = stack.pop();
    if (item === "/" && right === 0) {
      console.log("ERROR");
      process.exit(0);
    }
    stack.push(
      item === "+"
        ? left + right
        : item === "-"
          ? left - right
          : item === "*"
            ? left * right
            : left / right,
    );
  }
}
console.log(Number.isFinite(stack[0]) ? stack[0].toFixed(1) : "ERROR");
```
