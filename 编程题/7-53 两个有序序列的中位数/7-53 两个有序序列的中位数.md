## 题目描述

已知有两个等长的非降序序列 S1、S2，设计函数求 S1 与 S2 并集的中位数。

**中位数定义**：对于有序序列 A₀, A₁, ⋯, A_{N-1}，其中位数指 A_{(N-1)/2} 的值，即第 ⌊(N+1)/2⌋ 个数（A₀ 为第 1 个数）。

## 输入格式

1. 第一行给出序列的公共长度 N（0 < N ≤ 100000）
2. 第二行输入序列 S1 的 N 个非降序排列的整数
3. 第三行输入序列 S2 的 N 个非降序排列的整数
4. 数字用空格间隔

## 输出格式

在一行中输出两个输入序列的并集序列的中位数。

## 输入样例

```in
5
1 3 5 7 9
2 3 4 5 6
```

## 输出样例

```out
4
```

## 输入样例

```in
6
-100 -10 1 1 1 1
-50 0 2 3 4 5
```

## 输出样例

```out
1
```

## 样例说明

### 样例 1 分析

- S1 = [1, 3, 5, 7, 9]
- S2 = [2, 3, 4, 5, 6]
- 并集排序后：[1, 2, 3, 3, 4, 5, 5, 6, 7, 9]
- 总长度 N = 10，中位数位置为第 ⌊(10+1)/2⌋ = 5 个数（从 1 开始计数）
- 第 5 个数是 **4**

### 样例 2 分析

- S1 = [-100, -10, 1, 1, 1, 1]
- S2 = [-50, 0, 2, 3, 4, 5]
- 并集排序后：[-100, -50, -10, 0, 1, 1, 1, 1, 2, 3, 4, 5]
- 总长度 N = 12，中位数位置为第 ⌊(12+1)/2⌋ = 6 个数（从 1 开始计数）
- 第 6 个数是 **1**
