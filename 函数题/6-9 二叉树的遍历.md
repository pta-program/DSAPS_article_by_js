## 6-9 二叉树的遍历

- **分值：** 25分

## 题目描述

本题要求给定二叉树的4种遍历。

## 函数接口定义
```javascript
// JavaScript 函数接口
function InorderTraversal(BT) {}
function PreorderTraversal(BT) {}
function PostorderTraversal(BT) {}
function LevelorderTraversal(BT) {}
```

其中`BinTree`结构定义如下：

```javascript
class TreeNode {
  constructor(data, left = null, right = null) {
    this.Data = data;
    this.Left = left;
    this.Right = right;
  }
}
```

要求4个函数分别按照访问顺序打印出结点的内容，格式为一个空格跟着一个字符。

## 裁判测试程序样例
```javascript
const tree = new TreeNode("A", new TreeNode("B"), new TreeNode("C"));
console.log(`Inorder: ${InorderTraversal(tree).join(" ")}`);
console.log(`Preorder: ${PreorderTraversal(tree).join(" ")}`);
console.log(`Postorder: ${PostorderTraversal(tree).join(" ")}`);
console.log(`Levelorder: ${LevelorderTraversal(tree).join(" ")}`);
```

## 函数部分

```javascript
// 深度优先遍历分别在左根右、根左右、左右根三个时机记录结点；层序用队列。
function InorderTraversal(BT) {
  const out = [];
  (function walk(n) {
    if (!n) return;
    walk(n.Left);
    out.push(n.Data);
    walk(n.Right);
  })(BT);
  return out;
}
function PreorderTraversal(BT) {
  const out = [];
  (function walk(n) {
    if (!n) return;
    out.push(n.Data);
    walk(n.Left);
    walk(n.Right);
  })(BT);
  return out;
}
function PostorderTraversal(BT) {
  const out = [];
  (function walk(n) {
    if (!n) return;
    walk(n.Left);
    walk(n.Right);
    out.push(n.Data);
  })(BT);
  return out;
}
function LevelorderTraversal(BT) {
  const out = [],
    queue = BT ? [BT] : [];
  for (let i = 0; i < queue.length; i++) {
    const n = queue[i];
    out.push(n.Data);
    if (n.Left) queue.push(n.Left);
    if (n.Right) queue.push(n.Right);
  }
  return out;
}
```

## 解题思路

中序、先序和后序遍历都使用递归，区别只在于访问根结点的时机：中序是“左、根、右”，先序是“根、左、右”，后序是“左、右、根”。层序遍历需要借助队列，先访问根结点，再按从左到右的顺序将孩子结点入队。四种遍历的时间复杂度均为 `O(n)`；前三种的递归栈空间为 `O(h)`，层序遍历的队列空间为 `O(n)`。

## 代码流程说明

1. 递归遍历遇到空树立即返回。
2. 中序、先序、后序函数分别在不同位置打印当前结点数据。
3. 层序遍历先将根结点入队，循环取出队首并打印。
4. 每次取出一个结点后，依次将其左、右孩子入队，队列为空时结束。
