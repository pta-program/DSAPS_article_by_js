## 6-8 求二叉树高度

- **分值：** 20分

## 题目描述

本题要求给定二叉树的高度。

## 函数接口定义
```javascript
// JavaScript 函数接口
function GetHeight(BT) {}
```

其中`BinTree`结构定义如下：

```javascript
class TreeNode {
  constructor(data, left = null, right = null) {
    this.Data = data;
    this.Left = left;
    this.Right = right;
  }
}
```

要求函数返回给定二叉树BT的高度值。

## 裁判测试程序样例
```javascript
const tree = new TreeNode(
  "A",
  new TreeNode("B", new TreeNode("D"), new TreeNode("F", new TreeNode("E"))),
  new TreeNode("C", new TreeNode("G", null, new TreeNode("H")), new TreeNode("I")),
);
console.log(GetHeight(tree));
```


## 函数部分

```javascript
// 空树高度为 0；非空树高度是左右子树较大高度加 1。
function GetHeight(BT) {
  if (BT === null) return 0;
  return Math.max(GetHeight(BT.Left), GetHeight(BT.Right)) + 1;
}
```

## 解题思路

采用递归定义树高：空树高度为 0，非空树高度等于左右子树高度的较大值加 1。递归会覆盖每个结点一次，因此时间复杂度为 `O(n)`；递归栈的空间复杂度为 `O(h)`，其中 `h` 是树高。

## 代码流程说明

1. 若当前结点为空，返回 0。
2. 递归计算左子树和右子树的高度。
3. 取两个高度中的较大值并加 1，作为当前树高返回。
