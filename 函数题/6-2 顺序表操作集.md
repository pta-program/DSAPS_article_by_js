## 6-2 顺序表操作集

- **分值：** 20分

## 题目描述

本题要求实现顺序表的操作集。

## 函数接口定义
```javascript
// JavaScript 函数接口
function MakeEmpty() {}
function Find(L, X) {}
function Insert(L, X, P) {}
function Delete(L, P) {}
```

其中`List`结构定义如下：

```javascript
// 顺序表对象用 Data 数组保存元素，Last 保存最后一个有效下标。
const MAXSIZE = 5;
const ERROR = -1;
// { Data: number[], Last: number }
```

各个操作函数的定义为：

`List MakeEmpty()`：创建并返回一个空的线性表；

`Position Find( List L, ElementType X )`：返回线性表中X的位置。若找不到则返回ERROR；

`bool Insert( List L, ElementType X, Position P )`：将X插入在位置P并返回true。若空间已满，则打印“FULL”并返回false；否则，如果参数P指向非法位置，则打印“ILLEGAL POSITION”并返回false；

`bool Delete( List L, Position P )`：将位置P的元素删除并返回true。若参数P指向非法位置，则打印“POSITION P EMPTY”（其中P是参数值）并返回false。

## 裁判测试程序样例
```javascript
const L = MakeEmpty();
[1, 2, 3, 4, 5, 6].forEach((x) => {
  if (!Insert(L, x, 0))
    process.stdout.write(` Insertion Error: ${x} is not in.\n`);
});
for (const x of [6, 5, 1]) {
  const p = Find(L, x);
  console.log(
    p === ERROR
      ? `Finding Error: ${x} is not in.`
      : `${x} is at position ${p}.`,
  );
}
for (const p of [-1, 6]) {
  if (!Delete(L, p)) console.log(" Deletion Error.");
  if (!Insert(L, 0, p)) console.log(" Insertion Error: 0 is not in.");
}
```

## 输入样例
```
6
1 2 3 4 5 6
3
6 5 1
2
-1 6
```

## 输出样例
```
FULL Insertion Error: 6 is not in.
Finding Error: 6 is not in.
5 is at position 0.
1 is at position 4.
POSITION -1 EMPTY Deletion Error.
FULL Insertion Error: 0 is not in.
POSITION 6 EMPTY Deletion Error.
FULL Insertion Error: 0 is not in.
```

## 函数部分

```javascript
// 插入从后向前搬移，删除从前向后搬移，避免覆盖尚未处理的元素。
function MakeEmpty() {
  return { Data: [], Last: -1 };
}
function Find(L, X) {
  for (let i = 0; i <= L.Last; i++) if (L.Data[i] === X) return i;
  return ERROR;
}
function Insert(L, X, P) {
  if (L.Last + 1 >= MAXSIZE) {
    process.stdout.write("FULL");
    return false;
  }
  if (P < 0 || P > L.Last + 1) {
    process.stdout.write("ILLEGAL POSITION");
    return false;
  }
  for (let i = L.Last; i >= P; i--) L.Data[i + 1] = L.Data[i];
  L.Data[P] = X;
  L.Last++;
  return true;
}
function Delete(L, P) {
  if (P < 0 || P > L.Last) {
    process.stdout.write(`POSITION ${P} EMPTY`);
    return false;
  }
  for (let i = P; i < L.Last; i++) L.Data[i] = L.Data[i + 1];
  L.Data.pop();
  L.Last--;
  return true;
}
```

## 解题思路

顺序表用 `Last` 记录最后一个有效元素的下标，空表时令 `Last = -1`。查找从下标 0 线性扫描；插入时先判断容量和位置合法性，再从后向前移动元素；删除时从被删位置开始，将后续元素依次前移。插入和删除都必须按照对应方向移动，避免覆盖尚未处理的数据。

## 代码流程说明

1. `MakeEmpty` 分配表结构并把 `Last` 初始化为 `-1`。
2. `Find` 遍历 `[0, Last]`，找到 `X` 返回下标，否则返回 `ERROR`。
3. `Insert` 先判断是否满表，再判断 `P` 是否在 `[0, Last + 1]`；从 `Last` 到 `P` 逆序移动，写入 `X` 并更新 `Last`。
4. `Delete` 判断 `P` 是否在 `[0, Last]`；将 `P` 后面的元素前移，最后减小 `Last`。
