# DSAPS_by_C

PTA《数据结构与算法题目集（中文版）》的 C 语言练习代码仓库。

本仓库按题号保存题目实现及对应说明，内容只覆盖当前仓库中的题目，不包含统一工程、公共库或批量测试脚本。

## 仓库内容

- `编程题/`：53 道完整程序。每道题通常包含一个可独立编译运行的 `.c` 文件和一个同名 `.md` 文件。
- `函数题/`：12 道函数实现题。`.c` 文件只实现题目要求的函数，需要放入 PTA 题目提供的裁判程序中运行。
- 图片文件：部分题目的说明或过程图使用的本地图片资源。

当前统计：65 道题、65 个 C 源文件、65 个 Markdown 说明文件。

## 目录结构

```text
DSAPS_by_C/
├── 编程题/
│   └── 7-题号 题目名称/
│       ├── 7-题号 题目名称.c
│       └── 7-题号 题目名称.md
├── 函数题/
│   └── 6-题号 题目名称/
│       ├── 6-题号 题目名称.c
│       └── 6-题号 题目名称.md
└── README.md
```

每个 `.md` 文件包含对应题目的题意、输入输出样例、解题思路及代码说明；具体实现以同目录下的 `.c` 文件为准。

## 编译与运行

### 编程题

编程题源文件包含 `main` 函数，可以使用 GCC 单独编译。由于路径和文件名包含中文及空格，建议使用引号包围路径：

```bash
gcc -std=c11 -Wall -Wextra -O2 \
  "编程题/7-1 最大子列和问题/7-1 最大子列和问题.c" \
  -o solution

./solution < input.txt
```

也可以直接在 PTA 对应题目中提交源文件内容。程序从标准输入读取数据，并将结果输出到标准输出。

### 函数题

函数题源文件不是完整的可执行程序，通常依赖题目中预先定义的类型、宏、头文件和裁判测试程序。使用方法如下：

1. 打开对应的 `.md` 文件，确认函数接口和裁判程序中的类型定义。
2. 将 `.c` 文件中的函数实现复制到裁判程序指定位置，或合并到裁判程序中编译。
3. 使用 PTA 题目提供的输入进行测试。

仓库没有统一的 Makefile 或其他构建系统；每个题目都是相互独立的实现。
